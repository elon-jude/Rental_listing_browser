# Rentify — Rental Listings Browser

A simple two-screen Flutter app built for the Rental Listings Browser task.

## Requirements covered

- Screen 1: scrollable list of 8 rental listings with title, location and price.
- Search bar filters by property title or location.
- Location dropdown filters by location.
- Price dropdown filters by price range.
- Screen 2: tapping a listing opens a property detail screen.
- Detail screen includes description, bedrooms, bathrooms, area, amenities and contact button.
- Uses `StatefulWidget` + `setState`; no Provider/BLoC required.
- Uses only Flutter SDK + Material 3; no external API or database required.

## Run

1. Make sure Flutter is installed.
2. Open this folder in VS Code or Android Studio.
3. Run:

```bash
flutter pub get
flutter run
```

For Android emulator/device:

```bash
flutter run
```
